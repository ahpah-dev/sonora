## Splendid Grand Piano sample bank

Sonora's Studio Grand sound uses public-domain Steinway grand-piano recordings from the Splendid Grand Piano sample set. The source includes the SFZ key mapping and velocity layers; Sonora packages selected roots from its four velocity layers as OGG files for in-browser playback.

- Sample set and SFZ mapping: [sfzinstruments/SplendidGrandPiano](https://github.com/sfzinstruments/SplendidGrandPiano)
- OGG distribution and sample metadata: [danigb/samples](https://github.com/danigb/samples/tree/main/audio/splendid-grand-piano)
- Original samples are identified by the source project as public domain (AKAI sample set).

The `index.json` file maps MIDI pitches and velocity layers to the bundled OGG recordings.
